# Validate author inputs, not generated resources

The Authoring Library validates each rule during validation-mode JSON Schema generation. It uses Pydantic's generated schemas to locate the target and every Path Operand, retaining reachable union branches and deriving cardinality from JSONPath syntax. It then validates a private `{target, assert}` document with the packaged Assertion Meta-Schema and renders Paths as `$path`. Compatibility comes only from explicit `type` declarations reachable through `allOf`, `anyOf`, and `oneOf`; validation keywords do not imply types. It does not preflight its complete generated resource against the Contract meta-schema: the Authoring Library owns generation, while the Validation Engine owns contract validation. On ruled models, `$schema`, `$id`, `x-validations`, and legacy `x-constants` are reserved author inputs.
